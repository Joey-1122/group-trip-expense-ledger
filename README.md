# 多人旅行，一人管账

这是一个给 AI Agent 使用的多人旅行记账 Skill：一名旅行成员负责报账，Agent 创建可直接查看的账本，并持续处理记录、AA 分摊、外币、改账、查账和最终结算。

## 开始使用

1. 把本仓库地址交给支持 Skill 的 Agent，让它读取 `SKILL.md`。
2. 首次启用时，Agent 会先说明账本如何保存、如何查看，以及记错后怎么修改，不会直接创建 JSON 糊弄用户。
3. 对 Agent 说：

   > 我要去韩国旅行，帮我记账。

4. Agent 会逐步引导：先确认同行人，再推荐一份你能直接打开的账本；境外旅行还会询问外币现金和交通卡/储值卡准备。不会一次抛出一长串问题。
5. 建好后直接自然语言报账：

   - `同行人 A 付了 30000 韩元吃饭，四个人。`
   - `我付了晚饭 240，四个人 AA。`
   - `刚才那笔改成只有我和同行人 A。`
   - `现在谁欠谁？`

## 设计原则

- 多人旅行，一人统一管账；
- 用户只需自然语言，不需要理解表格字段和分摊模型；
- JSON、数据库可作为后台底账，但不能是唯一交付物；
- 创建前说明账本格式、位置、所有权，并征得用户同意；
- 每笔新增或修改都同步可见账本并给出回执；
- 已知信息不重复问，每轮只问一个主题；
- 只有缺失信息会导致算错时才追问。

## V1 范围

- 一趟当前旅行；
- 一个人替所有同行人记账；
- 默认 AA，也支持个人消费、请客、各付各的和自定义金额；
- 支持外币现金、交通/储值卡、信用卡或线上支付换算；
- 支持自然语言改账、撤销、统计和结算；
- 不处理多人同时编辑、并行旅行、退款或复杂账单。

## Agent 需要具备

- 能读取本 Skill；
- 能创建并持续更新一种用户可直接查看的账本；
- 能持久化并重新打开同一账本；
- 需要外币换算时，有可靠汇率来源，或明确向用户询问/标记估算。

Skill 不绑定飞书、腾讯表格、本地电脑、云端或手机的具体实现；宿主 Agent 选择真实可用的方案，但必须满足可见、可持续和可追溯。

## 文件结构

- `SKILL.md`：完整操作流程与用户体验要求；
- `references/user-journey.md`：首次启用到最终结算的用户旅程；
- `references/ledger-schema.md`：最小逻辑账本结构；
- `references/accounting-rules.md`：分摊、外币和结算规则；
- `references/conversation-examples.md`：关键对话示例；
- `scripts/trip_ledger.py`：确定性的分摊与结算辅助脚本。
