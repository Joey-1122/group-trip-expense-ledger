# 多人旅行，一人管账

把这个 Skill 交给支持持久化存储的 Agent，它会让一名旅行成员用自然语言统一记录全员消费，自动处理共同/个人消费、代付、外币现金、储值卡、统计和最终结算。

## 怎么用

1. 下载本仓库，或把仓库地址交给你的 Agent。
2. 让 Agent 读取根目录的 `SKILL.md`。
3. 告诉它旅行名称、同行成员，以及哪个名字是你。
4. 之后直接自然语言记账，例如：

   - `同行人B付了 96 打车，三个人`
   - `同行人B帮我买药 45`
   - `晚饭各付各的，我 68，同行人B 82，同行人A 75`
   - `我用 2217 人民币换了 5 万日元现金`
   - `刚才那笔改成只有我`
   - `现在谁欠谁？`

## 适合什么场景

- 一趟多人旅行，由一个人统一记账；
- 默认 AA，也支持个人消费、请客、各付各的和自定义金额；
- 人民币与外币现金、Suica 等储值卡混合使用；
- 途中随时纠错、查每个人的付款额和承担额；
- 旅行结束后生成清晰的转账建议。

## Agent 需要具备什么

- 能读取本 Skill；
- 有一种可持续读写的存储方式；
- 需要实时汇率时，能调用自己的汇率来源。

Skill 不绑定飞书、微信、腾讯表格、本地文件或某种数据库。宿主 Agent 自己选择存储实现，并向用户说明账本保存在哪里。

## 文件结构

- `SKILL.md`：Agent 的主操作流程；
- `references/ledger-schema.md`：最小账本结构；
- `references/ledger-rules.md`：分摊、外币和结算规则；
- `references/examples.md`：常见对话示例；
- `scripts/trip_ledger.py`：确定性的分摊与结算辅助脚本。
